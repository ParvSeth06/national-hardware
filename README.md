# National Hardware — House of Hardwares

A modern, minimalist product-focused storefront for **National Hardware** (House of Hardwares), located in Ashwini Bazaar, Hathipole, Udaipur.

## Features
- **Product Storefront**: Browse 18+ stainless steel handle models with standard vs. Royal PVD finish pricing.
- **Quote Cart**: Interactive quote drawer with live quantity adjustments (+ / -).
- **WhatsApp Integration**: Instant formatted order dispatch directly to WhatsApp (+91 94140 58177).
- **Responsive & Modern Design**: Dark obsidian & gold palette powered by Cormorant Garamond & Inter typography.
